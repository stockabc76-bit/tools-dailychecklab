어떤 도구를 먼저 쓰면 좋을까요?

목적에 맞는 도구를 고르면 작업이 훨씬 빨라집니다.

이미지 용량이 클 때

블로그, 쇼핑몰, 문서 첨부 전에 이미지 최적화로 크기와 품질을 조정해 보세요.

사진을 공개 공유할 때

위치 정보나 촬영 정보가 걱정된다면 EXIF 제거 사본을 만든 뒤 업로드하는 것이 좋습니다.

색상값이 필요할 때

로고나 이미지의 대표 색상을 확인하고 HEX/RGB 값을 복사할 수 있습니다.
이미지 기준

이미지 최적화는 결과를 보면서 조정하세요

이미지마다 선명도와 용량 차이가 달라서 하나의 숫자가 모든 파일에 맞지는 않습니다.

1

품질은 70~85%부터

웹 업로드용 이미지는 80% 전후에서 먼저 확인해 보세요. 더 가볍게 만들고 싶다면 70%대로 낮춰도 됩니다.

2

글자와 제품 경계 확인

상세페이지나 안내 이미지처럼 글자가 들어간 파일은 압축 후 글자가 흐려지지 않는지 꼭 확인해 주세요.

3

투명 PNG는 주의

최적화 결과가 JPG로 저장되는 경우 투명 배경이 사라질 수 있습니다. 로고나 아이콘은 미리보기 확인이 중요합니다.

원본 이미지는 따로 보관하고, 다운로드한 결과가 사용 목적에 맞는지 확인한 뒤 업로드하는 흐름을 추천합니다.
공유 전 확인

사진에는 생각보다 많은 정보가 남을 수 있어요

EXIF에는 촬영 기기, 시간, 위치 정보가 포함될 수 있습니다. 공개 게시 전에는 사본을 만들어 확인하는 습관이 좋습니다.

1

위치 정보 확인

스마트폰 사진에는 GPS 정보가 들어갈 수 있습니다. 집, 회사, 자주 가는 장소가 노출되지 않도록 주의해 주세요.

2

원본은 그대로 보관

EXIF 제거 도구는 공유용 사본을 만드는 용도로 사용하고, 중요한 원본 사진은 따로 보관하는 것이 좋습니다.

3

결과 파일 확인

투명 PNG나 특수한 이미지 파일은 JPG 사본으로 바뀌면서 표시 방식이 달라질 수 있습니다.

로고 작업

로고 흑백 변환은 문서 용도에 맞춰 고르세요

흑백, 그레이스케일, 단색은 비슷해 보여도 쓰임이 조금씩 다릅니다.

1

완전 흑백

대비가 강하게 필요할 때 좋습니다. 인쇄물, 도장 느낌의 로고, 단순 문서에 어울립니다.

2

그레이스케일

원본의 밝기 차이를 어느 정도 남기고 싶을 때 적합합니다. 부드러운 인쇄 결과가 필요할 때 확인해 보세요.

3

단색 변환

브랜드 컬러를 유지하거나 특정 색 계열로 통일하고 싶을 때 사용할 수 있습니다.

색상 확인

색상값은 대표 팔레트와 클릭 지점을 함께 보세요

이미지는 그림자, 그라데이션, 압축 상태에 따라 같은 색처럼 보여도 값이 다를 수 있습니다.

1

대표 색상 확인

팔레트는 이미지에서 자주 보이는 색을 빠르게 훑어볼 때 좋습니다.

2

정확한 지점 클릭

로고의 특정 부분이나 배경 색을 쓰고 싶다면 캔버스에서 원하는 지점을 직접 클릭해 주세요.

3

HEX와 RGB 복사

웹 디자인에는 HEX, 디자인 도구나 일부 편집 도구에는 RGB 값이 편할 수 있습니다.

글자수 기준

글자수와 바이트는 함께 확인하면 좋아요

제출 기준이 글자수인지 바이트인지에 따라 결과가 달라질 수 있습니다.

1

공백 포함

문서 제출 기준에서 띄어쓰기까지 포함할 때 참고합니다.

2

공백 제외

내용 자체의 분량을 볼 때 유용합니다. 자기소개서나 소개 문구를 다듬을 때 확인해 보세요.

3

UTF-8 바이트

한글은 보통 영문보다 더 많은 바이트를 사용합니다. 시스템 입력 제한이 있을 때 함께 확인하면 좋습니다.
