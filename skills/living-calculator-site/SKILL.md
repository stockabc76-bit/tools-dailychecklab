# 생활계산소 사이트 작업 스킬

## 핵심 원칙

생활계산소는 금융 전문 사이트가 아니라 일상 유틸리티 계산 사이트다. 새 기능은 "무료, 브라우저에서 처리, 입력값 저장 없음, 참고용"을 기본 톤으로 맞춘다.

기능을 넣을 때는 먼저 기존 구조와 스타일을 읽고, 새 디자인을 만들기보다 `assets/styles.css`의 카드, 버튼, 헤더, 섹션 패턴을 재사용한다. 디자인 기준은 프로젝트 루트의 `design.md`를 함께 참고한다.

법률, 세금, 관세, 공공 기준처럼 바뀔 수 있는 내용은 공식 출처를 확인한 뒤 조심스럽게 쓴다. 확률, 당첨, 세금, 면세처럼 오해가 생길 수 있는 표현은 "보장", "확률 상승", "무조건" 같은 단정 표현을 피한다.

## 작업 순서

1. 현재 파일 구조를 확인한다.
   - 주요 파일: `index.html`, 개별 도구 HTML, `assets/styles.css`, 도구별 JS.
   - 공개 노출을 바꿀 때는 홈, 헤더 메뉴, 푸터, 메타 문구까지 함께 확인한다.

2. 기능 범위를 먼저 정한다.
   - 실제로 구현된 기능만 화면에 강하게 노출한다.
   - 보류 기능은 기존 파일을 삭제하지 말고 숨기거나 링크에서 제외해 나중에 다시 살릴 수 있게 둔다.
   - 예: OCR 품질이 부족하면 `receipt-ocr.html`은 보존하고 공개 동선은 다른 도구로 전환한다.

3. SEO와 콘텐츠를 정리한다.
   - `title`, `meta description`, `og:title`, `og:description`을 기능에 맞춘다.
   - 본문에는 사용 방법, 주의사항, 기준 설명을 넣어 광고용 페이지로 얇아 보이지 않게 한다.
   - 사용자가 바로 조작하는 도구 아래에 "사용 방법"을 배치하면 모바일에서도 읽기 쉽다.

4. UI를 기존 톤에 맞춘다.
   - 헤더 로고는 계산기 심볼 + 실제 텍스트 워드마크를 유지한다.
   - 주요 컬러는 딥그린/민트 계열을 사용한다.
   - 카드형 도구는 흰 배경, 얇은 라인, 큰 라운드, 부드러운 그림자를 유지한다.
   - 광고 영역은 승인 전에는 화면에 보이는 박스로 노출하지 말고 HTML 주석으로 위치만 남긴다.

5. 모바일을 반드시 확인한다.
   - 상단 메뉴는 모바일에서도 사라지지 않게 가로 스크롤 형태로 유지한다.
   - 홈 카드 링크가 모바일에서 엉뚱한 위치로 이동하지 않는지 확인한다.
   - 도구 접근이 너무 깊어지면 불필요한 카드나 반복 링크를 줄인다.

6. 브라우저에서 실제로 검증한다.
   - 로컬 미리보기 URL이 있으면 in-app browser로 열어 동작을 직접 클릭한다.
   - 입력, 결과, 링크 이동, 모바일 레이아웃, 콘솔 오류를 확인한다.
   - 중요한 화면은 스크린샷으로 남긴다.

7. 최종 폴더에 반영한다.
   - 최종 publish 폴더는 `D:\기능사잇\애드센스용\생활계산랩`이다.
   - 이 경로는 작업 권한 승인이 필요할 수 있으므로 복사 전 승인을 요청한다.
   - 복사 후 원본과 최종 폴더 파일 해시가 같은지 확인한다.

## 기능 추가 패턴

새 도구를 추가할 때는 다음 묶음을 같이 만든다.

- `tool-name.html`: 도구 UI, 설명, 사용 방법, 주의사항.
- `assets/tool-name.js`: 브라우저에서만 처리되는 계산 로직.
- `assets/styles.css`: 기존 컴포넌트를 확장하는 최소 스타일.
- `index.html`: 홈 메뉴, 히어로 미리보기, 기능 카드, 푸터 링크 반영.
- 정책/소개 페이지: 개인정보 처리 방식이나 서비스 소개가 바뀌면 함께 수정.

입력값은 서버로 보내지 않는 방향을 우선한다. 파일 업로드, OCR, 이미지 처리처럼 민감할 수 있는 기능은 "브라우저 내 처리" 여부와 한계를 분명히 쓴다.

## 콘텐츠 안전 기준

관세, 세금, 복권, 행정 기준은 최신 공식 기준을 확인한다. 공식 확인 전에는 "2026년 기준" 같은 시간 고정 문구를 쓰지 않는다.

로또 같은 확률형 콘텐츠는 다음처럼 표현한다.

- 좋은 표현: "패턴은 조합을 보기 쉽게 분류하는 참고 정보입니다."
- 피할 표현: "이 비율이면 당첨 확률이 높습니다."

관세 계산기는 예상 참고용으로 안내하고, 실제 납부세액은 관세청/통관 기준을 확인하라고 안내한다.

OCR은 추출 정확도를 보장하지 않는다. 결과를 수정 가능한 표로 보여주고, 사용자가 검수해야 한다는 문구를 유지한다.

## 검증 체크리스트

- 홈 히어로 링크가 각 도구로 이동한다.
- 모바일에서 헤더 메뉴가 보인다.
- 주요 도구 버튼이 클릭되고 결과가 갱신된다.
- 콘솔 오류가 없다.
- 화면에 승인 전 광고 박스가 보이지 않는다.
- 메타 문구와 푸터 브랜드명이 `생활계산소`로 통일되어 있다.
- 최종 폴더 반영 후 파일 해시가 일치한다.
