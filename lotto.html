반드시 포함

포함할 번호

선택한 번호는 생성 결과에 포함됩니다. 최대 6개까지 선택할 수 있습니다.

결과에서 제외

제외할 번호

선택한 번호는 생성 결과에 나오지 않습니다.

생성 결과

무작위 번호

아직 번호를 생성하지 않았습니다.

이용 안내

로또번호 생성기 사용 방법

  1. 포함할 번호에서 결과에 반드시 넣고 싶은 번호를 선택합니다. 선택하지 않아도 바로 생성할 수 있습니다.
  2. 제외할 번호에서 결과에 나오지 않게 할 번호를 선택합니다.
  3. 번호 6개 생성하기를 누르면 조건을 반영한 중복 없는 번호 6개가 무작위로 생성됩니다.
  4. 번호 복사하기로 결과를 복사하거나, 다시 생성으로 새 조합을 확인할 수 있습니다.

포함·제외 선택값과 생성 결과는 브라우저 안에서만 처리되며 별도로 저장하지 않습니다. 생성 번호는 참고용이며 당첨을 예측하거나 보장하지 않습니다.

참고용 조합 확인

로또번호 패턴 분석 방법

생성된 번호를 정리해 볼 때는 홀수와 짝수의 개수, 낮은 번호(1~22)와 높은 번호(23~45)의 개수, 연속 번호 여부, 여섯 번호의 합계를 살펴볼 수 있습니다.

홀짝 비율홀수와 짝수가 몇 개씩 포함되었는지 확인합니다.
고저 비율1~22번과 23~45번의 분포를 확인합니다.
연속 번호예: 14, 15처럼 이어지는 번호가 있는지 살펴봅니다.
번호 합계생성된 여섯 번호의 합계를 참고로 확인합니다.

주의: 모든 유효한 번호 조합의 추첨 확률은 동일합니다. 패턴은 조합을 보기 쉽게 분류하는 참고 정보이며, 특정 비율이나 합계가 당첨 확률을 높이지 않습니다.

지급 시 원천징수

복권 당첨금 세금 계산법 (2026년 기준)

복권 당첨금은 지급 시점에 세금이 원천징수됩니다. 동행복권 안내와 현행 과세 기준에 따르면 건별 당첨금이 200만원 이하인 경우 과세하지 않으며, 200만원을 초과하면 다음 세율이 적용됩니다.

당첨금 구간적용 세율
200만원 이하비과세
200만원 초과 ~ 3억원 이하22%
3억원 초과분33%
예시: 당첨금 10억원

3억원 x 22% = 6,600만원, 초과분 7억원 x 33% = 2억 3,100만원으로 계산해, 세금 합계는 2억 9,700만원이며 세후 금액은 7억 300만원입니다.

세율 안내는 2026년 기준 일반적인 계산 예시입니다. 실제 지급액과 적용 여부는 수령 시점의 법령 및 동행복권 공식 안내를 확인하세요.
